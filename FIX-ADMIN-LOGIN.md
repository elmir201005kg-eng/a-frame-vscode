# 🔧 Исправление проблемы входа в админ-панель

## ✅ Проблема решена!

Сессии в базе данных очищены. Теперь нужно очистить cookies в браузере.

## 🚀 Пошаговая инструкция:

### Шаг 1: Очистите cookies браузера

#### Вариант A: Через инструменты разработчика (РЕКОМЕНДУЕТСЯ)

1. Нажмите **F12** (откроется DevTools)
2. Перейдите на вкладку **Application** (или **Хранилище**)
3. Слева найдите **Cookies** → **http://localhost:3001**
4. **Удалите все cookies** (щелкните правой кнопкой → Clear)
5. Закройте DevTools

#### Вариант B: Через настройки браузера

1. Нажмите **Ctrl + Shift + Delete**
2. Выберите **"Cookies и другие данные сайтов"**
3. Выберите **"За всё время"**
4. Нажмите **"Удалить данные"**

#### Вариант C: Режим инкогнито (БЫСТРЫЙ СПОСОБ)

1. Нажмите **Ctrl + Shift + N** (Chrome/Edge)
2. Откройте админ-панель в инкогнито

### Шаг 2: Обновите страницу

1. Перейдите на: **http://localhost:3001/ru/admin-login**
2. Нажмите **Ctrl + Shift + R** (жесткая перезагрузка)

### Шаг 3: Войдите

```
Email: admin@frame.kg
Пароль: aframe2026!
```

После ввода учетных данных:
1. Вам придет код в Telegram
2. Введите 6-значный код
3. Готово! 🎉

## 🔄 Если проблема повторилась

### Метод 1: Очистите сессии в БД

```bash
npx tsx scripts/clear-admin-sessions.ts
```

### Метод 2: Удалите cookie вручную через DevTools

1. **F12** → вкладка **Application**
2. Найдите **Cookies** → **http://localhost:3001**
3. Удалите cookie с именем **`a-frame-session`**
4. Удалите cookie с именем **`a-frame-admin-login`** (если есть)
5. Обновите страницу (**F5**)

### Метод 3: Используйте другой браузер

Откройте в Firefox, Chrome, Edge или другом браузере.
