# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

# Проект: A-FRAME KG

## Онлайн-сервис поиска и бронирования A-frame домиков в Кыргызстане

**Курсовой / учебный проект**

**Frontend-разработка на React**

**Бишкек, 2026**

---

# 1. Общая информация о проекте

**Название проекта:** A-FRAME KG

**Тип проекта:** веб-приложение с мобильной адаптацией.

**Направление:** туризм, отдых и бронирование жилья.

**Основная технология:** React.

**Язык разработки:** JavaScript.

**Платформа:** Web.

**Основная концепция:** поиск и бронирование A-frame домиков в Кыргызстане.

A-FRAME KG — это современный онлайн-сервис, предназначенный для поиска уютных A-frame домиков для отдыха в различных регионах Кыргызстана.

Пользователь сможет открыть приложение, найти подходящий вариант, посмотреть фотографии, узнать стоимость, расположение, доступные удобства и отзывы.

После выбора домика пользователь сможет указать даты проживания, количество гостей и оформить демонстрационное бронирование.

Главный акцент проекта делается на понятный интерфейс, простую навигацию и удобный пользовательский сценарий.

---

# 2. Актуальность проекта

Кыргызстан обладает большим туристическим потенциалом. В стране есть горы, озёра, ущелья, леса и другие природные места, подходящие для отдыха.

Одним из современных вариантов размещения являются небольшие A-frame дома.

Информация о таких объектах часто размещается в социальных сетях и на разных интернет-ресурсах. Пользователю приходится самостоятельно искать фотографии, цены, расположение, условия проживания и отзывы.

A-FRAME KG решает эту проблему, объединяя информацию о домиках в одном сервисе. Это делает поиск более быстрым и понятным.

---

# 3. Цель проекта

Главная цель проекта — создать удобное современное приложение для поиска и бронирования A-frame домиков в Кыргызстане.

Пользователь должен иметь возможность пройти основной путь:

**Найти подходящий вариант → выбрать домик → ознакомиться с информацией → выбрать дату → оформить бронирование.**

Основная задача Frontend-части — реализовать понятный интерфейс, удобную навигацию и реалистичную работу основных функций без обязательного использования сложного Backend.

На первом этапе данные могут храниться в JSON, LocalStorage или предоставляться через Mock API.

В дальнейшем проект может быть подключён к полноценному серверу и базе данных.

USER — обычный пользователь сервиса. Он использует приложение для поиска подходящего места отдыха и оформления бронирования.

- редактировать профиль.

OWNER — владелец A-frame домика. Для него предусмотрен отдельный раздел приложения.

- войти в личный кабинет;

# 31. Логика интерфейса

При разработке интерфейса важно сохранять одинаковую навигацию на всех основных страницах.

Header используется на страницах каталога и информации.

Мобильная нижняя навигация обеспечивает быстрый доступ к:

- Home;
- Search;
- Favorites;
- Bookings;
- Profile.

Кнопки должны иметь понятные названия:

- «Найти»;
- «Забронировать»;
- «Добавить в избранное»;
- «Применить»;
- «Назад»;
- «Подтвердить».

# 34. Маршруты React Router

```text

/filters
/favorites
/booking

/profile
/bookings

/register
/owner
```

# 36. Работа с данными

На первом этапе полноценный Backend не является обязательным.

Данные о домиках могут храниться в JavaScript или JSON-файле.

## Пример объекта данных

```javascript
{
  id: 1,
  title: "Mountain A-Frame",
  location: "Иссык-Куль",
  price: 5000,
  guests: 4,
  rating: 4.9,
  image: "/images/mountain.jpg",
  amenities: [
    "Wi-Fi",
    "Кухня",
    "Парковка",
    "Отопление"
  ]
}
```

Axios может использоваться для получения данных из Mock API.

LocalStorage применяется для хранения:

- избранного;
- бронирований;
- данных пользователя;
- демонстрационного состояния авторизации.

# 43. Итог

A-FRAME KG — это Frontend-проект для поиска и бронирования A-frame домиков в Кыргызстане.

Он объединяет:

- каталог;
- поиск;
- фильтры;
- подробную информацию;
- фотографии;
- отзывы;
- избранное;
- бронирование.

Проект реализуется с использованием:

- React;
- JavaScript;
- HTML;
- CSS;
- React Router;
- Axios;
- LocalStorage;
- JSON;
- Mock API.

На учебном этапе сложный Backend не требуется.

В Excalidraw создаётся архитектура из **21 мобильного экрана**, связанных переходами.

В дальнейшем проект может быть расширен:

- сервером;
- базой данных;
- онлайн-оплатой;
- картой;
- уведомлениями;
- панелью администратора;
- мобильными приложениями Android и iOS.

Таким образом, **A-FRAME KG** соответствует требованиям задания и может использоваться как основа для дальнейшего развития коммерческого продукта.
