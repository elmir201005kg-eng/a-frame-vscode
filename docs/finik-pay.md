# Finik Pay

Интеграция основана на `FINIK_INTEGRATION_GUIDE.md`. Сумма платежа фиксирована: **5 KGS** (`lib/finik-config.ts`). Цены проживания в каталоге и бронировании сохраняются отдельно; они не используются при создании платежа.

Гость открывает детали своей реальной брони и нажимает «Оплатить 5 сом». `POST /api/finik/create-payment` принимает `{ "bookingId": "123", "locale": "ru" }`, проверяет сессию и принадлежность брони, сохраняет UUID платежа и возвращает URL из ответа Finik `302 Location`. Сумма и пользователь определяются на сервере. Демонстрационные, отменённые, отклонённые и уже оплаченные брони недоступны для оплаты.

`POST /api/finik/webhook` проверяет `signature`, `x-api-timestamp` (не старше пяти минут), сумму, аккаунт и связь UUID с бронированием. Подпись проверяется и в beta, и в prod. `SUCCEEDED`/`succeeded` устанавливает `PAID`, ID транзакции и дату оплаты; `FAILED`/`failed` устанавливает `FAILED`. Повторные уведомления не дублируют записи и не понижают статус полученной оплаты. После неудачной оплаты доступна новая попытка. Получение денег после отмены записывается и создаёт уведомление о необходимости возврата. Подтверждение проживания остаётся действием владельца.

Возврат на `/{locale}/bookings/{id}?payment=success` ожидает webhook и обновляет страницу. Сам redirect не подтверждает оплату. Запрос, не получивший ответ от Finik, можно повторить спустя 30 секунд с прежним UUID; готовая ссылка переиспользуется.

Переменные в `.env`: `FINIK_ENV` (`beta`/`prod`), `FINIK_API_KEY`, `FINIK_ACCOUNT_ID`; в prod также `FINIK_PRIVATE_KEY` в формате PEM. Адрес сайта выбирается из `NEXTAUTH_URL`, затем `NEXT_PUBLIC_APP_URL`, затем `APP_URL`. Без этих переменных используется Origin входящего запроса после проверки совпадения с Host. За reverse proxy передавайте исходный Host или задайте канонический адрес: внутренний адрес Next.js не должен попасть в webhook/redirect. При заданном каноническом адресе его Host используется для проверки подписи webhook. Для prod необходим HTTPS. Для получения webhook при локальном запуске нужен публичный адрес туннеля, указанный в одной из этих переменных.

Добавлена миграция `20261013000300_finik_pay`: UUID провайдера и ссылка оплаты в `payments`. При развёртывании выполните `npm run db:deploy` и `npm run db:generate`.

Проверки: `npm run test:finik`, `npm run lint`, `npm run build`. Автоматические тесты используют тестовые RSA-ключи и подменённый HTTP/БД; реальные платежи не создаются. Для полной проверки Finik выполните оплату и дождитесь подписанного webhook на публичном сервере.
