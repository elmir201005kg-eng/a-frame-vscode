# Анализ и очистка A-FRAME KG

Дата: 22 октября 2026 года.

## Область анализа

Проверены структура приложения, граф импортов 207 исходных модулей, маршруты, серверные действия, компоненты, стили, переводы, схема БД, зависимости, конфигурация и существующие проверки. Проанализирована текущая рабочая копия с ранее внесёнными незакоммиченными изменениями.

| Область | Текущее устройство |
| --- | --- |
| Платформа | Next.js 16.4, React 19, TypeScript; App Router, Cache Components и частичная предварительная загрузка |
| Публичная часть | Главная, каталог с фильтрами, направления, инструкция бронирования, фотогалерея, страницы домиков, условия и политика конфиденциальности |
| Личный кабинет | Профиль, избранное, бронирования и настройки |
| Владельцы | Управление домиками, фотографиями и календарём |
| Администрирование | Домики, брони, платежи, пользователи, владельцы, справочники, отзывы, уведомления, переводы, настройки и журналы |
| Данные | PostgreSQL, Prisma 7, миграции, проверка доступности и расчёт проживания на сервере |
| Интеграции | Google OAuth, Telegram, Finik Pay и AI-консультант |
| Локализация | RU, KG и EN; JSON-словари с возможностью переопределения переводов через БД |
| PWA | Установка приложения и отдельная предварительно сформированная офлайн-главная для каждого языка |

Перед изменениями прочитаны локальные руководства установленной версии Next.js по страницам, общим макетам, стилям и навигации.

## Что удалено

1. На главной убраны два повторяющихся рекламных блока: короткие преимущества под поиском и отдельная сетка преимуществ. Поиск, подборка домиков, описание сервиса, предложение владельцам и FAQ остаются доступными.
2. Убрана вторая кнопка полного каталога под подборкой. Ссылка «Вся подборка» в заголовке сохранена.
3. Из шапки убрана дополнительная кнопка каталога. В мобильном меню также оставлен один переход к каталогу. По уточнению пользователя пункт «Главная» возвращён первым в основное и мобильное меню на всех трёх языках.
4. В подвале убраны повторные ссылки на личный кабинет и избранное; эти действия доступны в шапке. Контакты, навигация и ссылки на документы сохранены.
5. Удалены три неиспользуемых исходных файла: `components/cabin-card.tsx`, `components/favorite-button.tsx`, `lib/favorites.ts`. Они реализовывали старую карточку и локальное избранное; рабочая версия использует `PropertyCard`, `PropertyFavorite` и серверное избранное.
6. Из `lib/landing-data.ts` удалены старые демонстрационные карточки и их типы. Направления сохранены; актуальные демонстрационные данные в `prisma/demo-cabins.ts` не затронуты.
7. Удалены 133 неиспользуемых правила CSS: стили удалённых блоков, старых всплывающих окон, вкладок и фильтров. Общие стили действующих карточек, форм, просмотрщика фотографий и административных страниц сохранены.
8. Из трёх словарей главной удалены 432 устаревших значения: тексты удалённых элементов и старого демонстрационного интерфейса. Название пункта «Главная» восстановлено на всех языках; состав оставшихся ключей одинаков.
9. Удалены пять неиспользуемых SVG из шаблона Next.js: `next.svg`, `vercel.svg`, `file.svg`, `globe.svg`, `window.svg`.
10. Шаблонное начало README заменено описанием проекта; исправлены адрес разработки, сведения о шрифте и точках входа.

## Что учтено при очистке

Пакеты, которые не встречаются в обычных импортах, дополнительно проверены по конфигурации и способу запуска. Prisma Client используется через сгенерированный клиент, Tailwind — через CSS и загрузчик Turbopack, инструменты проверки — через CLI. Оснований удалять эти зависимости нет; версии в `package.json` согласованы с lock-файлом.

`lib/image-credits.ts` содержит сведения об авторах и лицензиях используемых фотографий. Эти сведения сохранены, хотя модуль сейчас не импортируется интерфейсом.

Существующая интеграция Finik использует фиксированные 5 KGS. Очистка интерфейса не изменяет сумму, статусы и порядок оплаты. Проверка боевого платежа не проводилась.

Авторизация, разграничение ролей, серверные действия, миграции и данные пользователей не изменялись. Незакоммиченные изменения, существовавшие до очистки, не сбрасывались. Удалённые исходники и ресурсы перед редактированием проверены на использование.

## Проверка результата

- TypeScript: `node node_modules/typescript/bin/tsc --noEmit --incremental false` — без ошибок до и после очистки.
- ESLint для `app`, `components`, `lib`, `scripts`, `tests` и конфигурационных файлов — без ошибок и предупреждений.
- Finik: 21 модульный тест пройден; ответы провайдера и операции с БД заменены заглушками. Из-за ограничения запуска дочерних процессов использован режим Node `--test-isolation=none`.
- AI: 36 модульных тестов пройдены; используются заглушки БД и ответов модели.

- Chrome / Playwright: пройдены 36 проверок страниц и размеров экрана. Главная проверена на ширинах 320, 768 и 1440 px для каждого языка; каталог, направления, инструкция, фотогалерея, документы, вход, регистрация и офлайн-главная — на 1440 px для каждого языка. Проверены открытие и закрытие мобильного меню, доступность избранного и юридических ссылок, отсутствие удалённых дублей. HTTP-ответы успешные; ошибок выполнения, гидратации и горизонтального переполнения не обнаружено.
- Проверены совпадение ключей трёх словарей и отсутствие ошибок пробелов в изменённых файлах через `git diff --check`.

Отчёт браузерной проверки и снимки русской главной сохранены в локальной игнорируемой папке `test-results/cleanup/`.

- Production-сборка `npm run build` завершена успешно: сформированы 102 страницы, сгенерирован PWA service worker с 64 офлайн-ресурсами и главными страницами на всех трёх языках.

Проверки создания аккаунтов, записи бронирований и административных изменений в реальной БД в рамках очистки не запускались. Это не полный аудит безопасности или проверка всех внешних интеграций.
