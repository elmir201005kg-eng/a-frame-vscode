# Фотогалерея домиков

`/{locale}/portfolio` показывает фотографии опубликованных домиков с проверенными владельцами из активных регионов. Действуют те же правила видимости и демонстрационного режима, что и в каталоге. Черновики не показываются. Подборка ограничена 60 последними домиками и шестью фотографиями на домик; все снимки доступны на странице самого домика.

Регионы в фильтре формируются из показанных фотографий. Просмотр позволяет перелистывать снимки кнопками и стрелками клавиатуры, закрывается через Escape и возвращает фокус на кнопку открытия. Из галереи можно перейти к соответствующему домику. Демонстрационные фотографии сохраняют отметку.

Фотогалерея доступна из основного меню и подвала. Политика конфиденциальности и условия использования доступны из подвала на всех трёх языках. В каталоге отображается количество применённых фильтров. Интервалы главной сокращены до 48 / 36 / 24 px на компьютере, планшете и телефоне; убрана лишняя кнопка продолжения пустой подборки.

Существующая интеграция Finik сохраняет фиксированную сумму 5 KGS. Кнопка «Создать тестовую заявку» на странице демонстрационного домика открывает Finik Pay сразу после создания заявки. В деталях подходящей брони при отсутствии настройки провайдера выводится сообщение с переходом к контактам. Оплаченные и недоступные для оплаты брони не показывают предложение оплатить повторно.

## Проверка

`npm run test:finik` проверяет подписи, webhook, сумму 5 KGS, повторные запросы, оплату тестовых заявок и запрет оплаты чужих броней. Реальные платежи не создаются.

Браузерные проверки используют существующий QA-runner с отдельной временной схемой PostgreSQL. Нужен `E2E_DATABASE_URL` или `DATABASE_URL`; платёжные реквизиты в этом запуске отключаются. Схема удаляется после завершения.

```powershell
$env:NEXT_DIST_DIR = '.next-gallery-qa'
npm run build
$env:E2E_PRODUCTION_DIR = '.next-gallery-qa'
$env:QA_REUSE_BUILD = 'true'
$env:QA_GREP = 'gallery:'
node scripts/performance-qa.mjs
```

Проверяются фильтры и сброс каталога, исключение черновиков из фотогалереи, перелистывание фотографий, восстановление фокуса и прокрутки, юридические ссылки и отсутствие горизонтального переполнения на ширинах 320, 768 и 1440 px для RU, KG и EN. Снимки сохраняются в `test-results/`.
