# Упрощение административной панели

Дата: 22 октября 2026 года.

Проверены все разделы админки, компоненты страниц, маршруты, запросы показателей и существующие тесты. Главное меню сокращено с 19 до 7 пунктов. Рабочие операции перенесены в связанные разделы; данные и ограничения доступа сохранены.

## Основное меню

| Пункт | Дополнительные инструменты |
| --- | --- |
| Главная | Четыре показателя, последние бронирования, ссылка на аналитику |
| Домики | Отзывы, акции, категории, регионы, удобства |
| Бронирования | Календарь занятости |
| Платежи | Список, фильтры и экспорт CSV |
| Пользователи | Сообщения пользователям |
| Владельцы | Проверка и подтверждение профилей владельцев |
| Настройки | Переводы и единый журнал действий |

Дополнительные инструменты открываются через навигацию внутри соответствующей страницы. Уведомления доступны через колокольчик в верхней панели. На узком экране внутренние ссылки можно прокручивать по горизонтали.

## Удалённые повторы

- «Поддержка» и «Сообщения» показывали одну форму рассылки уведомлений, без системы входящих обращений. Оставлена страница сообщений; старый `/admin/support` перенаправляется в `/admin/messages` с сохранением параметров.
- «Активности» и «Журнал действий» использовали одну таблицу событий. Оставлен единый журнал с фильтром всех действий либо действий администраторов. Старый `/admin/activities` перенаправляется в `/admin/audit` с сохранением параметров; `scope=admins` включает фильтр администраторов.
- Главная и аналитика раньше отображали одинаковый набор блоков. Теперь главная содержит бронирования, выручку, ожидающие решения заявки, домики на проверке и таблицу последних бронирований. Графики, распределение статусов и популярность находятся в аналитике.
- С главной удалены быстрые ссылки, повторявшие меню, две ленты событий, повторявшие журнал и уведомления, технические подписи и индикатор, не обеспечивавший автоматического обновления.
- Удалены декоративные подписи в боковой панели и нижний служебный подвал.
- Форма личного профиля свёрнута в настройках и открывается сразу из меню аккаунта. Смена пароля и завершение сессий собраны в один блок безопасности.

Удалён неиспользуемый `components/admin-recent-events.tsx` и 36 неиспользуемых CSS-селекторов. На главной больше не выполняются запросы для графиков и популярных направлений; аналитика не загружает таблицу последних бронирований. Проверки прав и правила расчёта подтверждённой выручки сохранены.

Дополнительно исправлены определение активного раздела и цикл перехода на главную админки в локальной кыргызской версии без префикса `/kg`. Доступ к панели по-прежнему проверяет защищённый серверный layout.

## Проверки

- TypeScript и ESLint для изменённых компонентов и маршрутов — без ошибок.
- Актуальная production-сборка с отдельным `NEXT_DIST_DIR` успешно сформировала 102 страницы.
- Пройдены проверки реальных агрегатов панели, исключений при расчёте выручки, поиска, фильтрации и пагинации; проверки административного доступа, модерации и защиты от поддельных запросов.
- Пройден сценарий всех разделов и старых ссылок, семи основных пунктов меню, внутренних вкладок, переключения трёх языков, мобильного меню, клавиатуры и отсутствия ошибок гидратации. Главная проверена на ширинах 320, 375, 430, 768, 1024 и 1440 px для каждого языка.
- Отдельно пройдена адаптивность 18 сочетаний рабочей страницы, языка и ширины экрана: календарь, домики, бронирования, платежи, категории и настройки.
- Отдельно пройдена локальная кыргызская версия: возврат на главную, отправка периода, открытие профиля внутри настроек и запрет анонимного доступа.

В ходе первоначальной проверки исправлены переход на главную в локальной кыргызской версии и зависание переключения языка между корневыми макетами Next.js. После перехода на React и Vite язык и профиль открываются через общий React-маршрутизатор без загрузки нового документа; профиль остаётся внутри административных настроек. Актуальное поведение описано в `docs/react-migration.md`.

После миграции на React/Vite полный `npm run test:admin` прошёл: 21 успешная проверка и 1 намеренный пропуск сценария локальных адресов в production. Включены загрузка фотографий, календарь, бронирования, права доступа и новые проверки навигации. Дополнительно все 3 проверки React-навигации прошли в Vite dev, включая кыргызские адреса без `/kg`, историю браузера и мобильное меню. TypeScript, ESLint, 4 серверных runtime-теста и `npm run build` с `BUILD_DIR=dist-admin-review` также прошли.

Снимки упрощённой панели: `test-results-admin/admin-desktop.png` и `test-results-admin/admin-calendar-mobile.png`. Локальные результаты QA игнорируются Git.

QA-скрипт `npm run test:admin` создаёт новую случайную схему `aframe_qa_*`, применяет в ней миграции и тестовые данные, отключает Google, Telegram и Finik и удаляет только свою схему после проверки. Реальные аккаунты, бронирования, платежи и фотографии проверками не изменяются.
